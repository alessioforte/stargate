// This file demonstrates the policy syntax supported by the ACE engine.
// Policies are defined as comments using the following syntax:
//
// // ALLOW|DENY subject FOR "resource" [WHEN condition];
//
// Where:
// - ALLOW/DENY: The action to take
// - subject: The entity requesting access (user, api_key, service, etc.)
// - resource: The resource being accessed (quoted string)
// - condition: Optional boolean expression with AND/OR logic
//
// Examples of supported operators:
// - == (equals)
// - != (not equals)
// - AND (logical and)
// - OR (logical or)
//
// Values can be:
// - Strings: "admin", "read", etc.
// - Booleans: true, false
// - Numbers: 1, 42, -10
