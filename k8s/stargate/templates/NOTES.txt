{{- if .Values.bootstrap.enabled }}
The idempotent bootstrap hook provisions the first administrator and Console OAuth client.
Inspect it with:
  kubectl logs --namespace {{ .Release.Namespace }} job/{{ include "stargate.fullname" . }}-bootstrap
{{- else }}
No administrator is provisioned automatically. Enable `bootstrap` or run:
  kubectl exec --namespace {{ .Release.Namespace }} deployment/{{ include "stargate.fullname" . }} -- /bin/server admin bootstrap --help
{{- end }}
